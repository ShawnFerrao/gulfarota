# Gulf Aorta Summit — Homepage Redesign Concept

A pitch concept: a single-page, self-contained redesign of the [Gulf Aorta Summit](https://gulfaorta.com) (GAS 2026) homepage, built to show what a rebuilt site could look like.

- **Single file** — `index.html` is fully self-contained (fonts embedded as base64, no external requests, no build step).
- **Direction** — an editorial, journal-style layout with a vascular-line motif (ink navy + antique gold), built around the event's real programme, chairman's letter, organising committee and accreditation details.
- **Status** — homepage only, a design concept, not the live site. Copy is drawn from the current gulfaorta.com content; partner/society logos are placeholders pending real assets.

## View it

Open `index.html` directly, or enable **GitHub Pages** for this repo (Settings → Pages → Deploy from branch → `main` / root) to get a shareable link.

## Stack

Plain HTML/CSS/vanilla JS — no framework, no dependencies. Fonts: Newsreader (display), IBM Plex Sans (body), IBM Plex Mono (labels/data), all self-hosted as `@font-face` data URIs.
